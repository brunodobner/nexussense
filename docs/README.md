# Documentação

Nada aqui vai junto numa instalação — é tudo ferramenta de manutenção.

| | o que é | quando ler |
|---|---|---|
| [armadilhas.md](armadilhas.md) | sintoma, causa e comando de verificação de cada erro que já custou tempo | **antes** de mexer no driver, no build ou no instalador |
| [decisoes.md](decisoes.md) | por que o projeto é como é: o que foi escolhido, a medição que sustenta, e o que foi descartado | antes de mudar uma decisão de desenho |
| [estado.md](estado.md) | onde o trabalho está e o que ficou pendente | ao retomar o projeto |
| [interface.md](interface.md) | o sistema visual da janela e da bandeja | ao mexer na GUI |
| [verificacao-manual.md](verificacao-manual.md) | o que a suíte automatizada não alcança, e por quê | antes de dar uma versão por boa |

## Histórico

O desenvolvimento aconteceu em 111 commits entre 2026-09-04 e 2026-09-11. Esse
histórico foi descartado na v1.0.0, e as specs e planos daquele período saíram
junto — mas **não sem antes serem lidos**: a razão que vivia neles está em
[decisoes.md](decisoes.md) e [armadilhas.md](armadilhas.md).
